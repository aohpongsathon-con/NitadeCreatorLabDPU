# Nitade Creator Lab

เว็บไซต์ Nitade Creator Lab สำหรับเผยแพร่ข้อมูลพื้นที่ ห้อง อุปกรณ์ ทีมงาน และผลงานนักศึกษา

## ไฟล์หลัก

- `index.html` — หน้าเว็บไซต์หลักสำหรับพัฒนาและเผยแพร่
- `assets/` — รูปภาพ ไอคอน ไลบรารี และข้อมูลประกอบเว็บไซต์
- `nitade-creator-lab.html` — ไฟล์รวมแบบ standalone สำหรับใช้งานเฉพาะภายในเครื่อง จึงไม่ถูกติดตามใน Git

## ทำงานสลับระหว่างเครื่อง

ก่อนเริ่มแก้ไขทุกครั้ง:

```bash
git pull --rebase
```

ก่อนย้ายไปทำต่ออีกเครื่อง:

```bash
git add -A
git commit -m "อธิบายสิ่งที่แก้ไข"
git push
```

หลีกเลี่ยงการแก้ไฟล์เดียวกันค้างไว้พร้อมกันมากกว่าหนึ่งเครื่อง
